# 바이어 관리: 승인 탭 내 메일 발송 세부 탭

## 목적
`/admin/buyers`의 승인 탭에서 승인 메일을 보낸 사람과 보내지 않은 사람을 분리해, 남은 발송 작업을 바로 볼 수 있게 한다.

## 변경 범위
- `src/app/admin/buyers/AdminDashboard.tsx` 만 수정. DB·API·엑셀 export 변경 없음.

## 동작
- 상단 탭은 `대기 / 승인 / 거절 / 전체` 유지. 승인 카운트는 승인 전체 수.
- 필터가 `approved`일 때 상단 탭 아래에 세부 탭 표시: `메일 미발송 N` / `메일 발송 완료 N`.
  - 미발송: `status === "approved" && !approval_email_sent_at`
  - 발송 완료: `status === "approved" && approval_email_sent_at`
- 승인 탭을 클릭할 때마다 세부 탭은 `미발송`으로 초기화.
- 메일 발송 성공 시 로컬 state의 `approval_email_sent_at`이 갱신되므로 해당 건은 즉시 발송 완료로 이동.
- 발송 완료 건을 대기/거절로 바꾸면 해당 상단 탭으로 이동(발송 기록 유지).
- 전체 선택·일괄 처리는 현재 보이는 목록(세부 탭 적용 후) 기준.

## 스타일
- 세부 탭은 상단 탭보다 작게(12px, 좁은 패딩), 선택 시 브랜드색 `#7d0b1c` 테두리/글자.

## 테스트
- 수동 확인: 승인 탭 진입 시 미발송 기본 선택, 카운트 합 = 승인 수, 발송 후 이동, 타입체크(`pnpm tsc --noEmit`) 통과.
