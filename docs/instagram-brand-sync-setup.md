끝까지 마치면 GitHub Secrets에 `IG_ACCESS_TOKEN`과 `IG_USER_ID` 두 개가 등록되고,
매일 18:00에 인스타그램 `[BRAND BOOTH]` 게시물이 사이트에 자동 반영됩니다.

소요 시간은 대략 20~30분입니다. 결제나 심사(앱 리뷰)는 필요하지 않습니다.

> Meta 개발자 콘솔의 메뉴 이름과 버튼 위치는 수시로 바뀝니다.
> 아래 표기와 화면이 다르면, 같은 뜻의 항목을 찾으면 됩니다.

## 0. 준비 — 인스타그램 계정 유형 확인

`@caskcarnival` 계정이 **비즈니스** 또는 **크리에이터** 계정이어야 합니다.
개인 계정은 API로 게시물을 읽을 수 없습니다.

확인 방법 (인스타그램 앱):

1. 프로필 → 오른쪽 위 메뉴(≡) → **설정 및 개인정보**
2. **계정 유형 및 도구** 항목이 보이면 이미 프로페셔널 계정입니다.
   - 안에서 현재 유형(비즈니스/크리에이터)을 확인할 수 있습니다.
3. 이 항목이 없거나 "프로페셔널 계정으로 전환"만 보이면 → 전환합니다.
   **비즈니스**를 권장합니다.

전환해도 게시물·팔로워·DM은 그대로 유지됩니다.

> 페이스북 페이지는 **필요하지 않습니다.** 아래에서 쓰는 방식(Instagram 로그인)은
> 페이스북 페이지 연동 없이 동작합니다.

## 4. 액세스 토큰 발급 (`IG_ACCESS_TOKEN`)

3번 화면의 **2단계: 비즈니스 로그인 설정 생성** 또는
**토큰 생성**(Generate token) 영역에 연결된 계정이 표시됩니다.

4. 이 토큰은 **60일간 유효**한 장기 토큰입니다.

> 이 토큰은 계정 접근 권한과 같습니다. 메신저·메모 앱에 남기지 말고,
> 6번 단계에서 GitHub Secrets에 넣은 뒤 복사한 내용은 지워주세요.

## 5. 계정 ID 확인 (`IG_USER_ID`)

브라우저 주소창에 아래 주소를 넣고 엽니다.
`<토큰>` 부분을 4번에서 복사한 토큰으로 바꿉니다.

```
https://graph.instagram.com/v23.0/me?fields=id,username&access_token=<토큰>
```

이런 응답이 나옵니다.

```json
{ "id": "17841400000000000", "username": "caskcarnival" }
```

- `username` 이 `caskcarnival` 인지 확인합니다. 다른 계정이면 4번을 다시 합니다.
- `id` 값이 `IG_USER_ID` 입니다. 복사해 둡니다.

### 검증 — 게시물이 실제로 읽히는지 확인

같은 방식으로 아래 주소를 엽니다.

```
https://graph.instagram.com/v23.0/me/media?fields=id,caption,permalink,timestamp&limit=5&access_token=<토큰>
```

최근 게시물 5개의 캡션이 보이면 **설정 성공**입니다.
`[BRAND BOOTH]` 로 시작하는 캡션이 있으면 형식까지 함께 확인해 주세요.

에러가 나면 그 메시지를 그대로 알려주시면 됩니다.

## 캡션 작성 규칙 (게시물 올릴 때)

캡션 **첫 줄**만 읽습니다.

```
[BRAND BOOTH] 사쿠라오 증류소 | SAKURAO DISTILLERY | JP
```

- `[BRAND BOOTH]` 로 시작
- 그 뒤를 `|` 로 세 칸: `한글명 | 영문명 | 국가코드`
- 국가코드는 2글자 (`JP` 일본, `KR` 한국, `TW` 대만, `US` 미국, `GB` 영국·스코틀랜드,
  `IE` 아일랜드, `FR` 프랑스, `IN` 인도)
- 둘째 줄부터는 자유롭게 쓰셔도 사이트에 영향이 없습니다.

첫 줄 형식이 어긋난 게시물은 목록에 추가되지 않고 Actions 로그에 경고로 남습니다.
