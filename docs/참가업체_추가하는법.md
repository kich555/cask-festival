# 참가 업체 추가하는 법

참가 업체 목록은 **`src/content/brands2026.json`** 파일 하나로 관리됩니다.
이 파일만 고치고 push하면 Vercel이 자동 배포합니다.

## 항목 하나 추가하기

`[` 와 `]` 사이에 아래 형태로 추가합니다. 항목 사이는 쉼표로 구분합니다.

```json
[
  {
    "slug": "sakurao-distillery",
    "nameKo": "사쿠라오 증류소",
    "nameEn": "SAKURAO DISTILLERY",
    "country": "JP",
    "logo": null,
    "link": "https://www.instagram.com/p/XXXXXXXXXXX/"
  }
]
```

| 항목 | 설명 |
|---|---|
| `slug` | 영문 소문자 + 하이픈. 중복되지 않게. 로고 파일명으로도 씀 |
| `nameKo` | 한국어 화면에 보일 이름 |
| `nameEn` | 영어 화면에 보일 이름. 로고가 없을 때 이니셜(앞 두 단어의 첫 글자)로도 쓰임 |
| `country` | 국가코드 2글자 → 국기로 표시. `JP` `KR` `TW` `US` `GB`(영국·스코틀랜드) `IE` `FR` `IN` |
| `logo` | 로고가 없으면 `null`. 있으면 `"/brands/파일명.png"` |
| `link` | 인스타 게시물 주소 등. 없으면 `null` (카드가 링크되지 않음) |

표시 순서는 **JSON에 적힌 순서 그대로**입니다.

## 로고 넣기

1. 로고 파일을 `public/brands/` 폴더에 넣습니다 (예: `sakurao-distillery.png`)
2. 해당 업체의 `"logo": null` 을 `"logo": "/brands/sakurao-distillery.png"` 로 바꿉니다

로고는 정사각형에 가깝고 배경이 투명한 PNG가 가장 예쁘게 나옵니다.
로고가 없는 동안에는 회색 타일에 영문 이니셜이 표시됩니다.

## 주의

- 쉼표와 따옴표를 빠뜨리면 빌드가 실패합니다. 헷갈리면 그냥 저에게 목록을 주세요.
- 마지막 항목 뒤에는 쉼표를 붙이지 않습니다.
