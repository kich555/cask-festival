브랜드 로고 폴더입니다.

■ 여기 있는 파일
  사이트가 실제로 쓰는 로고만 있습니다. 파일명은 업체 slug 기준입니다.
  (예: taepyung-brewing.png = 태평양조)
  직접 수정하지 마세요. 아래 절차로 다시 만들어집니다.

■ 새 로고를 추가하려면
  1. 이 폴더에 파일을 그냥 넣습니다. 파일명은 자유입니다.
     업체의 한글명·영문명 중 아무거나 들어 있으면 알아서 찾아갑니다.
       예)  태평양조.png / TAEPYUNG.jpg / 태평양조(로고).png
     png · jpg · webp · avif · svg 모두 가능합니다.
  2. 알려주시면 아래 두 명령을 돌려 반영합니다.
       python3 scripts/import-brands.py   (엑셀 → 업체 데이터)
       node scripts/link-logos.mjs        (로고 연결)
  3. 연결이 끝나면 넣으신 원본은 지워도 됩니다.
     사이트용 파일이 따로 만들어지고, 원본은 git 기록에 남습니다.

■ 자동으로 처리되는 것
  · 로고 가장자리의 빈 여백과 액자형 테두리 제거
  · SVG · AVIF → PNG 변환
  · 로고 배경색을 읽어 카드 배경에 적용
